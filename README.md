# F11 自动放卡脚本

F11 自动放卡工具：循环执行 **E → 点卡片 → 点召唤Boss**，并在召唤倒计时期间等待后继续下一轮。
F12 自动瞄准工具：识别区域内随机刷出的怪物，按识别误差发送相对鼠标移动，把准星拉到怪物身上，**只瞄准不开枪**。

完整的安装、取点、打包和排错步骤见 **[使用说明.md](使用说明.md)**。

## 使用

启动后主界面有 F11 放卡和 F12 瞄准两组功能：

- **F11循环次数**：本次要成功召唤的轮数。
- **召唤成功后等待（秒）**：面板关闭后等待多久再按 E 开始下一轮，默认 5.0 秒，保存后生效；到点立即开始，不再额外随机等待。
- **F6 / F7 取点**：先手动按 E 打开召唤面板，鼠标指向卡片中央按 F6，指向“召唤Boss”按钮中央按 F7。
- **瞄准灵敏度增益（像素/计数）**：每 1 个鼠标移动计数换算成多少屏幕像素，用来抵消游戏灵敏度；偏了就调它（详见使用说明）。
- **显示目标预览标记**：勾上后瞄准运行时会在识别到的怪物位置画一个不吃鼠标的小标记，用来确认识别是否可靠。
- **F8 取怪物模板**：战斗画面里把鼠标放到怪物身体中央按 F8，程序截取 120×120 作为识别模板。
- **保存配置 / 重启脚本**：保存配置；重启键盘监听。
- **操作日志**：显示按键、点击、识别和失败原因。

按 F11 开始/停止放卡，按 F12 开始/停止自动瞄准；两个循环互斥，不能同时运行。开始前请关闭召唤面板、保持游戏在前台。

## F11 循环流程

1. 找到 `crossfire.exe` 窗口并切到前台（失败会提示手动点击游戏）。
2. 用按钮模板判断面板是否已打开：已打开就直接选卡；未打开则按 E，每秒 1 次，最多 30 次。召唤后游戏会显示“3秒后，可召唤出Boss”，所以 5 秒等待结束后会以每秒一次的节奏按 E 直到面板出现。
3. 点击卡片中心 → 等 0.3 秒 → 再次确认按钮仍在 → 点击“召唤Boss” → 最多等 3 秒确认面板关闭。
4. 面板关闭才计入一轮，随后等待设定秒数（默认 5 秒）到点立即按 E 开始下一轮，不再叠加随机间隔。
5. 选卡后按钮消失、点击后面板未关闭等失败只记录并跳过/不计入本轮；但单轮按 E 满 30 次仍未打开面板时会自动停止循环并写日志。按 F11 也可随时停止。

## F12 自动瞄准流程

1. 战斗画面里把鼠标放在**怪物身体中央**按 F8，程序截取以鼠标为中心的 120×120 图片保存为 `monster_template_custom.png`，并记住当时的客户区宽度。
2. 按 F12 开始：每次循环截图 → 在游戏客户区内多尺度匹配怪物模板 → 相似度 ≥ 0.72 才算命中。
3. 命中后计算「怪物中心 − 客户区中心（准星）」的像素误差，除以灵敏度增益换算成鼠标计数，用 `SendInput(MOUSEEVENTF_MOVE)` 发送**相对移动**把准星拉过去；误差 ≤ 4px 视为已对准不动，单次最多修正 120px，远处的怪物分几轮收敛而不是甩一次。
4. 循环间隔 50ms，每轮重新识别，因此怪物走动时会持续跟枪。**开枪完全由你自己按**，程序不发送任何点击。
5. 再按 F12 停止。瞄准期间临时关闭 Windows 指针加速（否则“计数→像素”不是线性关系），停止和退出时恢复。

放卡循环和瞄准循环互斥：F11 运行时按 F12 会被拒绝，反之亦然。

## 坐标与识别

点击位置按游戏客户区比例保存，不使用绝对屏幕坐标，因此移动或缩放游戏窗口后无需重新取点（面板布局不变时）。

默认比例按 1024×768 客户区标定。若分辨率或面板布局变化导致点击/识别不对，用 F6/F7 重新取点。F7 还会把按钮附近 80×20 的小块截图保存为 `summon_button_custom.png`，用于多尺度模板匹配；“清除记录的位置”恢复默认比例，但不删除已生成的模板图片。

配置文件 `config.json` 只保存：

```json
{
  "post_summon_seconds": 5.0,
  "card_point_ratio": [0.2695, 0.5013],
  "summon_point_ratio": [0.7676, 0.7409],
  "button_template_client_width": 1024,
  "aim_gain": 1.0,
  "aim_template_client_width": 1024
}
```

## 运行环境

- Windows 10/11 64 位，游戏使用窗口化/无边框窗口且未被遮挡。
- 64 位 Python 3.10～3.13；安装依赖：`python -m pip install -r requirements.txt`。
- 程序以管理员权限启动（`release.py` 会自动请求提升）。
- 双击 `启动.bat` 或执行 `python release.py` 即可运行。
- `config.json`、`summon_button_custom.png` 和 `monster_template_custom.png` 固定从程序所在目录读取。

本软件仅用于交流学习，严禁用于非法用途。程序不提供进程隐藏，也不保证避免游戏的异常输入检测；自动瞄准属于高危行为，可能触发反作弊并导致封号。
